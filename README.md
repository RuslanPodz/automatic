# ЛР3. Біграмні шифри та шифр Вернама

Навчальний веб-застосунок на JavaScript: шифр **Playfair**, **двоквадратний
біграмний шифр** (конвенція розділу 4.4 методички) і гамування **Вернама**
(XOR над байтами UTF-8).

> Алгоритми навчальні. Playfair і двоквадратний шифр не забезпечують
> секретності, а XOR без автентифікації не захищає цілісність. Для реальних
> систем потрібне автентифіковане шифрування (AES-GCM, ChaCha20-Poly1305).
> Не вводьте паролі, токени чи персональні дані.

## Запуск

Застосунок не потребує збирання, сервера чи залежностей.

1. Відкрийте `index.html` у сучасному браузері (Chrome, Firefox, Edge, Safari).
2. Оберіть алгоритм і операцію, введіть ключ і текст, натисніть **Шифрувати**
   (або `Ctrl+Enter` у полі введення).

Перевірено в Chromium 153 (headless, Playwright) і Node.js 22.23.

## Тестування

Потрібен Node.js 20 або новіший. Сторонніх пакетів немає, використовується
вбудований тест-раннер `node:test`.

```bash
npm test             # 54 автоматизовані тести
npm run demo         # короткі приклади для звіту
npm run experiment   # власні тексти examples/texts/ -> examples/results/
npm run chacha       # порівняння з ChaCha20-Poly1305 (node:crypto)
```

Генеративні тести використовують детермінований ГПВЧ із фіксованим seed
(лише для тестових даних, не для ключів), тому результат відтворюваний.

## Специфікація обробки даних

| Аспект | Правило |
|---|---|
| Алфавіт | `ABCDEFGHIKLMNOPQRSTUVWXYZ`; J замінюється на I |
| Нормалізація | Unicode NFC, потім верхній регістр (лише біграмні режими) |
| Сторонні символи | строгий режим (типово) - помилка; «зручний режим» - вилучаються, підготовлений текст показується |
| Заповнювачі | X між однаковими літерами й наприкінці непарного тексту; Q, якщо розділити треба X |
| Розшифрування | повертає підготовлений потік літер; X/Q автоматично не вилучаються |
| Біграмний шифротекст | лише літери алфавіту, парна довжина; пробіли між біграмами ігноруються |
| Два квадрати | 1-ша літера - лівий квадрат, 2-га - правий; при розшифруванні навпаки |
| Vernam | текст кодується в UTF-8 **без** нормалізації; ключ рівно тієї ж довжини в байтах |
| Випадковість | `crypto.getRandomValues` (системний CSPRNG); `Math.random` не використовується |
| Формати | текст - UTF-8 (суворе декодування); ключ і шифротекст - Base64 (суворе декодування) |
| Журналювання | відкритий текст і ключі не виводяться в консоль і нікуди не надсилаються |

## Можливості інтерфейсу

* вибір алгоритму й операції, перевірка ключів «на льоту»;
* відображення ключових квадратів і таблиці кроків із правилом для кожної
  біграми; наведення або фокус клавішею Tab підсвічує координати у квадраті;
* підготовлені біграми з позначенням вставлених заповнювачів;
* генерування ключа Vernam через CSPRNG; заміна наявного ключа лише після
  підтвердження; попередження при спробі використати ключ повторно;
* HEX-подання P, K, C для налагодження;
* імпорт текстових файлів і ключа `.b64`, експорт результату та ключа окремими
  файлами, копіювання в буфер;
* демонстрація наслідку повторного використання ключа;
* доступність: підписи полів, навігація з клавіатури, видимий фокус,
  повідомлення про помилки текстом (не лише кольором), світла й темна теми.

## Формати файлів

* `*.txt` - текст UTF-8.
* `cipher.b64`, `key.b64` - один рядок Base64 і завершальний перенос рядка.
  Ключ зберігайте й передавайте окремо від шифротексту.
